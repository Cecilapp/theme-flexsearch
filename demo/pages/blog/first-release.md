# First release of the FlexSearch theme

We are happy to announce the first release of the _FlexSearch_ component theme for Cecil. It brings a client side full-text search to any Cecil website, with a keyboard friendly modal inspired by DocSearch.

## What's inside

The index is a static JSON file generated at build time, and the FlexSearch library is loaded lazily, on the first search only.

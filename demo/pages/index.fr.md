# FlexSearch pour Cecil

Ce site est la démo du [thème composant _FlexSearch_](https://github.com/Cecilapp/theme-flexsearch) pour [Cecil](https://cecil.app).

Cliquez sur le bouton **Rechercher** de l’en-tête, ou appuyez sur `Ctrl`/`⌘` + `K`, puis essayez quelques recherches :

- `installation` ou `composer` pour trouver le guide d’installation
- `mode sombre` ou `propriétés` pour trouver les styles
- `version` pour trouver les articles du blog (affichés avec leur date)
- `recherhce` (sic) : la recherche approchée prend le relais quand rien ne correspond strictement

Les résultats sont groupés par section (_Documentation_ et _Blog_), et chaque page de documentation est découpée selon ses titres : un résultat renvoie directement à la bonne ancre.

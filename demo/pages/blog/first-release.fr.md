# Première version du thème FlexSearch

Nous avons le plaisir d’annoncer la première version du thème composant _FlexSearch_ pour Cecil. Il apporte une recherche plein texte côté client à n’importe quel site Cecil, avec une fenêtre pilotable au clavier inspirée de DocSearch.

## Au programme

L’index est un fichier JSON statique généré lors du build, et la bibliothèque FlexSearch n’est chargée qu’à la première recherche.
